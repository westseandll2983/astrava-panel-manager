## Overview

Astrava Panel is a web dashboard that consolidates operational and administrative work into one browser-accessible interface. From the dashboard, users can oversee bots, modify application settings, administer user records, and interact with database resources.

It is built for administrators and teams that want these responsibilities organized in a single workspace rather than spread across separate tools. The dashboard layout keeps the primary management areas close at hand.
